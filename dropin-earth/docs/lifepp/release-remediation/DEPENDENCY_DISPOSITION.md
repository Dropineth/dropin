# Dependency remediation

Baseline: `8ba02a3e7fe591b115162229510112220b4182b8`. This document describes dependency remediation, not production approval. The final MapLibre adapter / brace-expansion graph passed clean installation and the normal raw moderate audit: **0 vulnerabilities at every severity**. Six API compatibility tests passed. The actual browser verified visible boundaries before/after date changes and animation, plus the unavailable-WebGL2 path. Visual review found the swipe overlay repeated unequal Before/After fallback prefixes; those prefixes were removed so the shared status stays readable. The final rebuilt browser run passed both scenarios, and the fallback screenshot was visually checked. `dependency-remediation-receipt.json` binds this local development evidence to manifest hashes and records the dirty source scope; it is not a head-bound remote CI receipt.

## Compatibility decisions and inspected call sites

- **Next 15.5.26:** declared OpenNext AWS 4.1.0 peer accepts `>=15.5.21 <16`; Node 22.22.3 satisfies Next's engine. Matching plugin and all three apps move together. Next's optional sharp range accepts `^0.34.3 || ^0.35.4` in this patch.
- **MapLibre 6.4.1:** v6 changes the browser target to ES2022 and removes WebGL1. `rg` over `apps/web/src` found one import/constructor, in `NasaGibsEarthObservation.tsx`; its methods use supported raster/source/control APIs. Initial full typecheck caught that v6 has no default export; changing the caller to a namespace import fixed this without weakening TypeScript settings. Web typecheck then passed. The project already uses modern WebGL/deck.gl. WebGL2 failure must preserve the surrounding observation metadata/source links. No caller supplies external attribution HTML. A modern-browser test still does not establish support on all devices.
- **deck.gl adapter:** the new real browser test subsequently caught `Cannot read properties of undefined (reading 'height')` in the old MapboxOverlay custom-layer render, despite types/build passing. The maintainer's supported MapLibre integration is `MapLibreOverlay`. Its first stable release is 9.4.0 (9.3.7 does not exist), with core/luma ~9.4 peers. Replace the sole `@deck.gl/mapbox` import/dependency with `@deck.gl/maplibre` 9.4.0 and move core/layers 9.3.7 to 9.4.0; preserve the existing interleaved polygon, colors and geometry. The existing `as unknown as IControl` cast is removed. Source search across apps/packages/services/tests found no other MapboxOverlay or deck.gl source calls. The 9.4 upgrade notes concern custom picking shaders, controller gestures and fill-pattern extensions, none used by this plain PolygonLayer. Browser verification requires visible cyan boundary pixels above the raster, not merely canvas initialization.
- **deepmerge 8.0.0:** v8 changes default Map merging, exported type names, and mutation behavior; Prisma's inspected `dist/index.js` dynamically imports only `deepmerge` as c12's configuration merger, with remote/default extension disabled. Repository-wide source search found no direct deepmerge imports and no custom Prisma config. The new test nevertheless loads a real temporary Prisma config through Prisma 6 and checks nested migration/schema/datasource values. No Prisma source/compiled package patch is used.
- **TOML 4.2.0:** requires Node >=20, satisfied by CI Node 22. Its CommonJS `parse(input, options)` calls `input.toString()`, preserving Anchor's Buffer input. The inspected Anchor workspace loader calls only this API. Source search found Anchor use in `contracts/solana/tests/dropin-anchor.spec.ts`; no direct TOML use elsewhere. The test verifies the real repository config and parser security boundaries. No wallet is read and no chain RPC is sent.
- **Jayson 5.0.0:** the documented breaking change replaces uuid with native crypto; Node 22 provides it. Maintainer also removed stream-json and uses delimited TCP/TLS framing; the repository does not call these transports. Installed web3's `index.cjs.js` imports `jayson/lib/client/browser`; the entry point and callback transport contract remain in v5. Tests drive Anchor's actual web3 `Connection` with a local mock fetch and inspect responses and IDs. No Solana version or chain behavior is changed.
- **Scoped overrides:** deepmerge, TOML and Jayson are applied to their concrete parents. npm 10 initially retained the old undici despite the parent override; a top-level same-patch undici override and targeted lock refresh resolved the only consumer, Miniflare. Existing global sharp/nanoid/Hono overrides move to patched versions. `qs` is same-major and shared by the adapter's Express/body-parser chain. No test, audit threshold or CI requirement is removed.

`npm-audit-adapter-final-attempt1.json` and its stderr preserve the TLS failure. It was never interpreted as zero; a normal retry succeeded without changing registry, TLS, DNS, proxy or audit policy. The intermediate raw adapter audit reports both brace-expansion and minimatch; the subsequent 5.0.12 override and clean install resolved both.

`maplibre-browser-adapter-before-layer-order.txt` records the failed acceptance check. The diagnostic probe disabled that assertion solely to save the failed image; any PASS text in its diagnostic output is not acceptance. The first adapter browser run obtained 24 synthetic raster responses and no page exceptions, but its pixel assertion failed: the later raster layer obscured the custom boundary. The fix inserts the raster before the first custom layer using MapLibre 6's public `getLayersOrder()` / `getLayer()` methods, and updates the existing raster source with public `RasterTileSource.setTiles()` on date/animation changes. An initial implementation using `getStyle()` was rejected by TypeScript because serialized styles exclude custom layers; the final implementation does not cast around that exclusion or depend on an adapter-private layer ID. These APIs were checked in the installed published MapLibre 6.4.1 source/types. The official API website could not be fetched by the browser tool, so that fetch is not claimed as verification.

The browser uses synthetic local catalog/manifest/tile responses and software WebGL2. Its pixel checks verify the cyan polygon above the synthetic raster; they do not verify real NASA imagery, signatures, physical GPU coverage or source permission. Failed baseline browser logs are retained as `maplibre-browser-attempt1.txt`, `maplibre-browser-attempt2.txt`, and `maplibre-browser-diagnostic.txt`.

The final browser run used 84 intercepted synthetic tile responses. Boundary pixels remained visible initially, after a date change and after animation (`1624 / 1624 / 1626` cyan pixels). The forced unavailable-WebGL2 path made zero tile requests and preserved source metadata. The final fallback screenshot was visually reviewed after removing the unequal Before/After prefix that overlapped in swipe mode. Reviewable screenshots are `fixture-maplibre-interleaved-bounds.png`, `fixture-maplibre-refreshed-bounds.png`, `fixture-maplibre-animated-bounds.png`, and `fixture-maplibre-webgl2-fallback.png`; their hashes are in the final receipt.
